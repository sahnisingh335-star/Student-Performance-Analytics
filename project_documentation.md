# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

## 2. Objective
The objective of this project is to analyse student marks, calculate total and average marks, assign grades, identify pass/fail results, and compare student performance.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- CSV Dataset
- Visual Studio Code

## 4. Dataset Description
The dataset contains 20 students and 9 original columns: Student ID, Name, Department, Mathematics, Physics, Chemistry, English, Hindi, and Attendance.

## 5. Implementation
- Loaded the CSV dataset using Pandas.
- Used reusable functions to calculate total and average marks.
- Applied conditions to assign grades and Pass/Fail results.
- Used NumPy and Pandas to analyse class and subject performance.
- Identified the top five students.

## 6. Key Features
- Total and average marks calculation
- Grade calculation
- Pass/Fail classification
- Class performance analysis
- Subject-wise average comparison
- Top five performers
