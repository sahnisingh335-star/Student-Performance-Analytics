## Visualizations

This project uses Matplotlib to visualize student performance through four charts generated from the student dataset.

### 1. Subject-wise Average Marks
Compares average marks across Mathematics, Physics, Chemistry, English, and Hindi.

### 2. Top 5 Student Performers
Displays the five students with the highest average marks.

### 3. Pass vs Fail Analysis
Shows the number of students who passed or failed based on their average marks.

### 4. Distribution of Student Average Marks
Shows how student average marks are distributed across different score ranges.
